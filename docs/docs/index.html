Clients & agents

One trust boundary — the server. Four ways in.

CLI rootwatch / rw

Terminal control panel, local project scanner, and CI gate. Talks to any instance over /api/v1 with a Bearer token — or stays fully local with --no-upload. 

npm i -g @rootwatch/cli
rootwatch login --server https://app.rootwatch.dev --token rw_…
rootwatch doctor # connectivity + scope self-check
npm package → full reference: cli/README.md in the source repo

MCP For AI agents

Streamable HTTP MCP server at /mcp — posture, scans, listeners, credential inventory, remediation proposals. Or run the stdio bridge for desktop MCP clients. 

{
  "mcpServers": {
    "rootwatch": {
      "url": "https://app.rootwatch.dev/mcp",
      "headers": { "Authorization": "Bearer rw_…" }
    }
  }
}
MCP setup on the home page → stdio bridge: rootwatch mcp

API REST /api/v1

Org-scoped Bearer-token API for scripts and integrations: score, hosts, scans, vulnerabilities, events, reports, downloads. Scopes: read · scan · write · admin. 

curl -H "Authorization: Bearer rw_…" \
     https://app.rootwatch.dev/api/v1/score
API overview on the home page →

AGENT Fleet agent

Zero-dependency Node 18+ posture reporter — outbound HTTPS only, no inbound listeners, pairs by enrollment code or rw_… token. 

curl -fsSL https://rootwatch.dev/agent/install.sh \
  | sudo bash -s -- <control-url> [credential]
Agent README → install-termux.sh for Android

APP Desktop

Electron thin client for Linux — AppImage, deb, snap — plus a local "This device" sensor that reports posture to your instance.

Release binaries → AppImage auto-updates; deb/snap via store or manual
